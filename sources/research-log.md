## The reddit problem

The brief says "research heavily on reddit." `reddit.com` and the open mirrors
(redlib/libreddit instances) are **blocked for the fetch tool** — Anthropic's
crawler is denied, mirrors return 403. So direct reddit scraping is out.

Workarounds, in order of preference:
1. **User pastes threads.** Drop reddit URLs or copied threads into a file in
   `sources/` and I work from those. Highest signal.
2. **Search snippets.** Some reddit discussion surfaces in general web search;
   lower fidelity, captured ad hoc.
3. **Substack / blog / magazine discourse** (Epoché, Philosophy Now, outsider
   theory blogs) as a proxy for "what living readers argue about."
