# skills/ — meta-process skills

This folder is **not** Bataille content (that lives in `knowledge/` and the
discussion-forged `insights/`). It holds **meta-process skills** — reusable
methods for *how we work together* — distilled from our interactions and meant
to persist across sessions as long-term working memory.

Each file is one skill: a named failure mode or method, with an operational
procedure precise enough to follow. The project memory index (`MEMORY.md`)
points a new session here, so these skills get picked up at session start.

This folder **grows through the collaboration.** When an interaction teaches a
durable lesson about process — not about Bataille, but about how to think,
verify, divide work, or communicate — it gets captured here as a new skill.

## Skills

- **`granular-verification.md`** — verifying generated content at small,
  specific, in-flow units instead of surface approval. Counters the LLM failure
  mode where volume passes unchecked.
- **`knowledge-as-agent-blueprint.md`** — treating the knowledge dossier as
  quarry for a layered agent-psyche; the four-layer model (genetic / persona /
  purpose / context), the ⟦⟧ annotation convention, and three reading skills.
- **`layer-spirit.md`** — each layer is a different kind of intelligence and
  must read differently. Native register per layer (pattern catalog · voice
  fragment · manifesto · dry index) + the swap test. Forged after the prior
  annotation pass produced uniform-voice tagged variants of the same content.
- **`annotations-reach-outward.md`** — adds the moves a corpus-internal pass
  systematically misses. New tag vocabulary: ⊕ research-task (outward
  projection, hand-off to the background researcher), ⊗ philosophical-kin
  (family-of-refusals), ⚑ install-deep (rewire the lens, not the index).
  Plus the rule that reader-affect is persona feedstock and must not be
  flattened. Lifted from the collaborator's manual commentaries on Erotism's
  foreword.
