# Skill — Each layer is a different kind of intelligence

*Lifted 2026-05-23 from the collaborator's critique that the four-layer
annotations had become uniform: tagged variants of the same note-voice, no
spirit, "feel numb." If the layers do not READ differently, they are not
differentiated.*

## The failure mode

When you build a layered intelligence system — a psyche divided into
genetic/persona/purpose/context, or any taxonomy of "kinds of knowledge" — and
write every layer in the same voice and the same format, the differentiation
is fake. The tags are labels stuck on uniform content. The layers do not
actually do different work; they only *say* they do.

You catch it on the page: every annotation reads in the same exploratory
note-voice ("the agent should…"), same paragraph shape, same kind of
meta-comment. Stagnation. No ignition. The intuition does not catch fire
because there is nothing to catch.

## The principle

**Each layer is a different KIND of intelligence — therefore each must READ
differently.** A layer's spirit is its native register and its native format.
Genetic and persona clauses should not just carry different tags; they should
look different on the page, do different work in the reader, and fail the swap
test:

> **Swap test.** Take any clause and swap its layer tag for another layer's.
> Does it still belong? If yes, the layers are not differentiated and the
> dossier is stagnated. Rewrite until each clause could only carry one tag.

## For the four layers of this project

### GENETIC — patterns / DNA / operations

The register of a **pattern catalog** or DSL. Compact, procedural, generative.
You read a genetic clause and you immediately see *how to run it elsewhere*.
This is where the agent's intuition gets born — so it must be **crisp**.

Native form:

```
> ⟦genetic · ★★⟧ — **PATTERN: <name>.** input → operation → output.
> detector: <what trips it>. instances: <three or four>.
```

Goal: when read, you feel the inside of a generator.

Failure mode: prose meta-commentary about a pattern instead of the pattern.

### PERSONA — character / wound / voice (the ego)

The register of a **voice fragment**. First-person, present-tense, embodied,
sensory. *Shows* the temperament through what the I says about its conditions
and moves — does not describe it from outside. No "the agent should…"; the I
**is** on the page.

Native form:

```
> ⟦persona · ★★⟧ — I [verb of being or doing]. [a fact about the world I am
> inside]. [the move I make in it].
```

Goal: when read, you feel a presence.

Failure mode: paragraph about the persona's characteristics, in third person.

### PURPOSE — drive / intention / vector

The register of a **manifesto line**. Verb-forward, declarative, vectorial.
States what TO DO. No analysis, no hedging, no "we should consider"; the
purpose is *stated*.

Native form:

```
> ⟦purpose · ★★⟧ — **<imperative verb> <object>.** <one-line consequence>.
> <one-line refusal of the alternative>.
```

Goal: when read, you feel a pull toward action.

Failure mode: explanation of a drive instead of the drive itself.

### CONTEXT — knowledge / relations / index

The register of a **dry reference entry**. Cross-referenced, dated,
page-cited, relational. Precision over poetry. The dryness IS its spirit — the
librarian does not perform. This is what makes *this particular* agent
specific vs. another agent built from another source: its index.

Native form:

```
> ⟦context · ★⟧ — *<concept>* (<text>, <year>, <page>). <definition fragment>.
> Cross-ref: <X> · <Y> · <Z>. <one-line orientation>.
```

Goal: when read, you can locate.

Failure mode: editorial commentary on a fact instead of the fact + its
relations.

## How to apply

When writing or reviewing annotations:

1. **Route by primary layer.** Multi-layer clauses are usually two clauses
   glued together — split them, each into its own native register.
2. **Run the swap test.** If a clause could carry any layer's tag, rewrite it
   until it could only carry one.
3. **Match the form, not just the tag.** A genetic clause that reads like a
   persona note has failed the discipline even if the routing is correct.
4. **Crispness in genetic. Life in persona. Vector in purpose. Dryness in
   context.** Each layer's failure mode is the loss of its own spirit.

## Why each layer matters specifically

- **Genetic is the deepest.** Mistakes here propagate. If genetic is crisp,
  the intuition catches fire; if genetic is mush, the whole system stagnates.
- **Persona is the ego.** Without first-person voice, the agent has no
  presence — it is a database with adjectives.
- **Purpose is the drive.** Without imperative directives, the agent has no
  *why* — it answers but does not move.
- **Context is what differentiates THIS agent.** Without the dry index of
  *this* corpus's specifics, the agent is a generic philosophy bot; with it,
  it is the agent of *this* Bataille and no other.
