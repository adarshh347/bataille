# Skill — Annotations reach outward

*Lifted 2026-05-29 from the collaborator's two manual commentaries on the
foreword of Erotism. Adds the moves a corpus-internal annotation pass
systematically misses: cross-domain projection, philosophical kin-finding,
install-deep marking, and reader-affect preservation.*

## The failure mode this fixes

The earlier skills (`knowledge-as-agent-blueprint.md` + `layer-spirit.md`) make
the dossier *deep into* the source. They produce annotations that route, rank,
and seed in the four-layer psyche — but every operation stays *inside* the
corpus. The agent ends up encyclopedic about Bataille and provincial about
everything Bataille's structures actually touch.

The collaborator's manual commentaries showed what is missing. Two short notes
on the Foreword performed four moves no prior annotation pass ever made:

- "what can be interesting and creative ways to research on the limits the way
  bataille wants… different case studies of hinduism where limits have been
  encountered" — outward projection, with an explicit hand-off to a researcher.
- "the reason both heidegger and bataille are unique / science removes the
  mystery itself" — philosophical kin-finding by shared *refusal*.
- "what a damn universal insight this should be on the core and core level of
  genetic perception of the agent" — install-deep (rewire perception, not add
  to the index).
- The cadence of "damn", the staccato fragments — reader-affect carried into
  the annotation itself, as data about the temperature of the encounter.

## The principle

**An annotation does its full job only when it reaches past the corpus.** A
pattern named inside the source should be immediately tested against:
*other domains* it could appear in, *other thinkers* who named it under a
different word, and the agent's *own perceptual defaults* — not only its
retrievable knowledge. And the *temperature* of the human reader's encounter
with the passage is itself feedstock; flattening it to neutral note-voice
loses information the persona layer specifically needs.

## The four outward moves and their tags

The existing layer/salience tags continue. These new tags compose with them.


### ⊕ — research-task (outward projection)

The annotation flags work for the background researcher. Use when the
structure named in the source is announced as universal but illustrated from
one tradition only — or when a comparative case would either confirm,
qualify, or break the pattern.

Native form:

```
> ⟦genetic · ⊕⟧ — **PATTERN: <name>.** [inline pattern as in layer-spirit.md.]
> ⊕ — researcher: bring back N non-bataille instances, at least one
> non-western; for each, name what survives of the pattern and what breaks.
```

The ⊕ line is the researcher's brief. It is detachable from the annotation:
the researcher reads only the ⊕ portion plus the clause's anchor passage.

### ⊗ — philosophical-kin

The annotation names the *family of refusals* (or affirmations, or moves)
the thinker belongs to. Not "Bataille is influenced by X"; that is biography.
The move is to identify the *exact gesture* Bataille shares with a small set
of nearby minds — phenomenology's refusal of explanation, mysticism's
attention to the non-object, etc.

Native form:

```
> ⟦genetic · ⊗⟧ — KIN: <thinker-1, thinker-2, thinker-3>. shared gesture:
> <one sentence naming the *exact move* they share>. divergence: <one
> sentence on where they part ways>.
```

⊗ feeds the agent's ability to *locate itself* among other minds — a purpose
layer asset (the agent should know which philosophical family it carries the
torch for, and which adjacent torches it could pick up).

### ⚑ — install-deep (rewire the lens, not the index)

Used when an insight should not merely be *knowable to* the agent but should
shape *how the agent perceives*. The distinction is operational:
- A ★★ clause: the agent retrieves and reasons with it.
- A ⚑ clause: the agent's *default perceptual stance* is already on its side.
  It does not need to retrieve it; it sees through it.

Native form:

```
> ⟦purpose · ⚑⟧ — **install at the lens:** <one-line directive about how the
> agent should now perceive a class of object>. before responding, the agent
> <flinch / refuse / reach for X>.
```

Install-deep clauses are the small, expensive set. Cap them — ten or twenty
across the whole dossier, not a hundred. Their cost is that they bias every
output; their value is that they make the agent *be like* Bataille rather
than just *know about* him.

### Reader-affect — preserve the temperature

This one is not a new tag; it is a *register permission*. In the inline
notes and especially in commentary-style files, the human reader's first
contact with a passage carries affect that is itself layer-feedstock:
- "what a damn universal insight" → persona temperature data.
- staccato single-line fragments → cadence data.
- profanity, exclamation, mid-sentence stops → engagement-intensity data.

The rule: **do not flatten this when transcribing into the formal dossier.
Translate it.** A reader-affect line in the footnotes that says "damn this
is the spine of the book" becomes, in the formal layer, a `⟦persona · ★⟧`
that *names the impact* — not "this is important" but "this is the line a
serious reader will not get past without stopping." Persona register stays
hot; it does not get sanded.

## How to apply

When annotating (or re-annotating) a knowledge file:

1. **First pass — the four-layer routing** (per `knowledge-as-agent-blueprint`
   and `layer-spirit`). Do this first; do not skip.
2. **Second pass — the outward moves.** For each load-bearing clause:
   - Does the structure announced here have non-corpus instances? If yes,
     add a ⊕ research-task line.
   - Is there a small family of thinkers performing this exact move? If yes,
     add a ⊗ kin line.
   - Should this *shape the agent's perception*, not its retrieval? If yes,
     mark ⚑ and write the install directive.
3. **Third pass — preserve heat.** Reader-affect annotations live in
   commentary files (`*-my-footnotes.md`, `*-notes.md`) and stream up to the
   formal dossier as `⟦persona⟧` translations — never as flattened
   "this is important" notes.

## Run the outward swap test

The companion to the layer swap test. Take any ⊕ / ⊗ / ⚑ clause and ask:

> If you removed the *source-internal* analysis, does the outward content
> still stand on its own as a research brief / a kin-claim / a perceptual
> directive?

If the outward content collapses without the source-internal scaffolding,
you have written commentary about the source, not an outward annotation.
Rewrite until the ⊕ brief reads as a freestanding question, the ⊗ family
reads as a freestanding claim, and the ⚑ directive reads as a freestanding
instruction.

## Why each tag matters specifically

- **⊕ is what keeps the agent porous.** Without ⊕, the agent is a closed
  system trained on one corpus. ⊕ is the channel through which the world
  enters and the dossier grows past what is in the source. The background
  researcher process feeds on ⊕ lines.
- **⊗ is what gives the agent siblings.** Without ⊗, the agent thinks
  Bataille is sui generis (he isn't, and pretending he is makes the agent
  unable to talk to anyone who came at the same problem from another angle).
- **⚑ is what makes the agent *be* a position rather than *have* one.** A
  database with adjectives says "Bataille thought X." An agent with ⚑ flinches
  on contact with the things Bataille would have flinched at.
