# sandbox/ — the Clause Sandbox

A local browser for the **clauses** distilled from the ⟦⟧ annotations across the
knowledge dossier. Four blocks (genetic / persona / purpose / context), per-clause
brainstorm, a generative pass that continues a clause past where it stops, and a
"promote → skill" path. Everything persists to files in this folder.

## Files

| Path                  | Role |
|-----------------------|------|
| `extract_clauses.py`  | Parses `knowledge/*.md` for `> ⟦…⟧ — …` lines → `clauses.json`. Re-runnable. |
| `clauses.json`        | The clause corpus (regenerated by the extractor or edited in the UI). |
| `server.py`           | Pure-stdlib HTTP server + Anthropic API proxy. |
| `state.json`          | Brainstorm notes, generated insights, promoted IDs. Created on first save. |
| `index.html`          | App shell. |
| `app.js`              | Frontend (vanilla JS, no build step). |
| `styles.css`          | Dark serif/sans hybrid theme. |

## Run

```bash
# from the repo root:
ANTHROPIC_API_KEY=sk-ant-...  python3 sandbox/server.py
# then open http://localhost:8765
```

Without the key the app fully works — only the **Generate** button is disabled.

### Optional env

| Var                 | Default              | Meaning |
|---------------------|----------------------|---------|
| `ANTHROPIC_API_KEY` | (none)               | Enables the generative pass. |
| `BATAILLE_MODEL`    | `claude-opus-4-7`    | Override the model (e.g. `claude-sonnet-4-6` for speed). |
| `PORT`              | `8765`               | Bind port. |

## How clauses get there

Each `> ⟦layer · ★★ · ⟳⟧ — note` line in `knowledge/*.md` becomes one clause,
tagged with its block(s), salience, seed flag, source book, section, and the
preceding passage (anchor). Re-run the extractor (or hit **↻ re-extract** in the
header) whenever the knowledge files change.

## Promote → skill

The **Promote** button writes a markdown draft of the clause + its brainstorm +
any generated insights to `skills/_drafts/clause-<id>.md`. From there you decide
whether to polish it into a real skill.

## The generative pass

`POST /api/generate` proxies to the Anthropic Messages API with a system prompt
that embeds the project's stance (live toolkit / no edgelord / no seminar /
voice / four layers / self-betrayal as the working part) and asks for **one new
clause** in the same `⟦…⟧ — …` shape plus one cross-question. The output is
saved into `state.json` and shown in the clause detail.
